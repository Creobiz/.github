## 🚀 Overview
Creobiz is a dynamic marketplace platform designed to bridge the gap between local shopkeepers and digital creators. By facilitating hyper-local influencer marketing, the platform allows small-to-medium businesses to find, connect with, and hire digital creators to promote their products and services to highly targeted audiences. 

## ✨ Key Features
* **Dual-Portal Access:** Dedicated workflows and dashboards specifically tailored for both Businesses (Shopkeepers) and Digital Creators.
* **Smart Discovery:** Advanced search and filtering tools for businesses to find the perfect local influencer based on niche, engagement rate, and audience demographics.
* **Flexible Revenue Models:** Built-in support for both tiered subscription plans for active businesses and commission-based transaction structures for one-off campaign agreements.
* **Campaign Management:** End-to-end tracking of promotional campaigns, content deliverables, and performance analytics.
* **Secure Collaboration:** Streamlined communication, negotiation, and agreement features contained entirely within the platform.

## 🛠️ Tech Stack
* **Frontend:** React.js bootstrapped with Vite, styled with Tailwind CSS for a highly responsive, modern interface.
* **Backend:** Robust Java utilizing the Spring Boot framework to handle core business logic and API endpoints.
* **Database & Authentication:** Supabase for secure user authentication, role-based access control, and scalable relational data storage.
